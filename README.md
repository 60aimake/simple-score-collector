# 악보 모으기

유튜브 악보 영상의 화면을 **PDF 한 장**으로 모으는 도구입니다.
설치하지 않습니다. 브라우저에서 바로 씁니다.

**바로 쓰기 → https://60aimake.github.io/simple-score-collector/**

---

## 쓰는 법

1. 위 주소를 엽니다
2. **🖥 화면 보면서 자동으로 모으기** 를 누르고, 악보가 나오는 창을 고릅니다
3. 영상을 끝까지 재생합니다 — 악보가 바뀔 때마다 알아서 모읍니다
4. **📄 PDF로 저장** 을 누릅니다

악보 둘레에 군더더기가 많으면 **✂ 자를 자리 정하기** 로 네모를 끌어 악보만 남길 수 있습니다.

---

## 만들어진 것

- HTML 파일 한 장입니다. 바깥에서 가져다 쓰는 것이 없습니다
- 모은 그림은 **내 컴퓨터 밖으로 나가지 않습니다.** 어디에도 보내지 않습니다
